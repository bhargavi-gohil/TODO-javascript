# 📝 Todo Project (React)

A simple and intuitive Todo List application built with **React**.  
This project demonstrates core concepts of **state management, props, and component-based architecture**.

---

## 🚀 Features
- ➕ Add new tasks
- 📱 Responsive design for mobile and desktop

---

## 🛠️ Tech Stack
- **Frontend:** React, JSX, CSS
- **Tools:** Git, GitHub, VS Code
- **Package Manager:** npm 

---

## 📂 Project Structure
- `src/components/` → Contains reusable components (`TodoInput`, `TodoList`, `TodoItem`)
- `App.jsx` → Root component managing state and rendering child components
- `index.js` → Entry point for rendering the React app
- `public/index.html` → Base HTML file
